# 贪吃蛇游戏 (SDL2图形版)

一个使用SDL2图形库的贪吃蛇游戏，具有图形界面。

## SDL2依赖安装

### Ubuntu/Debian
```bash
sudo apt update
sudo apt install libsdl2-dev
```

### macOS (使用Homebrew)
```bash
brew install sdl2
```

### Windows
1. 下载SDL2开发库: https://www.libsdl.org/download-2.0.php
2. 将SDL2头文件和库文件放到相应目录
3. 修改Makefile中的编译选项

## 编译与运行

## 编译与运行

### 编译
```bash
make
```

### 运行
```bash
make run
# 或直接运行
./snake
```

## 游戏控制

- **W** / **w** 或 **↑** : 向上移动
- **S** / **s** 或 **↓** : 向下移动  
- **A** / **a** 或 **←** : 向左移动
- **D** / **d** 或 **→** : 向右移动
- **Q** / **q** 或 **ESC** : 退出游戏

## 游戏规则

1. 控制蛇吃到食物（*）
2. 每吃到一个食物得分增加10
3. 蛇撞到墙壁或自己的身体游戏结束
4. 蛇身会随着吃食物而变长

## 游戏界面

图形界面使用SDL2渲染：
- 黑色背景，灰色网格
- 红色矩形：蛇头
- 绿色矩形：蛇身  
- 黄色矩形：食物
- 灰色边框：墙壁

游戏窗口大小为600x600像素（20x20网格，每个格子30像素）。

分数显示在控制台窗口中，游戏窗口仅显示图形。

## 代码结构

- `snake.c` : 主程序文件
- 使用SDL2图形库进行渲染和输入处理
- 使用链表存储蛇身
- 支持Windows和Linux平台
- 非阻塞输入处理

## 在VS Code中运行

1. 在VS Code中打开包含 `snake.c` 的目录
2. 打开终端 (Ctrl+`)
3. 编译: `gcc snake.c -o snake`
4. 运行: `./snake`

## 注意事项

- 游戏速度通过 `SDL_Delay(100)` 控制（100毫秒）
- 游戏区域大小为20x20，每个格子30像素
- 需要安装SDL2开发库才能编译
- 分数显示在控制台，图形显示在SDL窗口
